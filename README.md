# Sthir — NSE swing research (paper trading only)

Open the site on iPhone (Safari → Share → Add to Home Screen) or Windows. A GitHub Action refreshes
`data/` with Nifty 200 + Nifty 50 daily prices from Yahoo every weekday at 18:47 IST.
Run it by hand: Actions → Refresh NSE data → Run workflow. The app never places orders.
